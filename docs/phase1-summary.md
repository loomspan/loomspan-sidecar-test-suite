# Phase 1: purpose and scope

Phase 1 used a realistic equipment-service process to take Loomspan Framework through
substantial end-to-end work. Its primary purpose was exploration: find bugs, understand
failure modes and discover features or refinements that practical skill authors need.

Two equivalent reference applications exercised embedded Java Framework and Python
with Sidecar. The workflow combined nested planning, parallel evidence retrieval,
model reasoning, deterministic pricing, authenticated approval and persistent records.
Multiple models exposed different interaction and business-reasoning weaknesses.

Phase 1 concluded on 2026-10-05. It achieved its exploratory purpose; it did not claim
exhaustive feature acceptance or general model reliability. On 2026-10-06 the user
approved retiring its accumulated tests, captures, archives and historical comparisons,
while keeping both current apps, skills and configuration for Phase 2.

A verified recovery snapshot was made outside the active repository before cleanup.
Routine Phase 2 work does not depend on it. Phase 2 studies skill design; Phase 3 will
establish durable regression coverage and release confidence.
